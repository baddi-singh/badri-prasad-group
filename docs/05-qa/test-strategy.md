# QA Test Strategy

## Objective
Ensure Badri Prasad Group website is stable, secure, professional, and production-ready.

## Testing Types
1. Smoke testing
2. Functional testing
3. Regression testing
4. API testing
5. Database testing
6. Security testing
7. Performance testing
8. Responsive testing
9. Cross-browser testing
10. Playwright automation

## Environments
- Local
- Staging
- Production

## Production Release Rule
No production release without staging smoke test and backup.
